# 서울시 생활인구 대시보드 내 지도 시각화(Folium) 추가 개발 계획

기존 Streamlit 대시보드에 서울시 지도 시각화 탭을 추가하고, Folium을 활용하여 자치구별/행정동별 시간대별 생활인구 밀도를 인터랙티브하게 지도 상에 나타낼 수 있도록 하는 확장 기능 개발 계획서입니다.

## 사용자 검토 필요 사항

> [!IMPORTANT]
> - **GeoJSON 지리 정보 자산 추가:**
>   - 서울시 자치구 경계 데이터인 `seoul_sig.geojson` (25개 구)과 행정동 경계 데이터인 `seoul_dong.geojson` (425개 동) 데이터를 인터넷 소스로부터 성공적으로 다운로드하여 `seoseoul-pops/data/` 폴더에 적재하였습니다.
> - **지도 시각화 성능 최적화:**
>   - 행정동 단위 지도 시각화의 경우 425개 동의 폴리곤 경계를 매번 렌더링하면 브라우저 부하가 크고 반응이 느려질 수 있습니다.
>   - 이를 방지하기 위해 사용자가 특정 자치구(예: 강남구)를 선택했을 때는 **해당 자치구에 속한 행정동의 폴리곤(보통 10~25개)만 GeoJSON에서 실시간 필터링하여 Folium에 전달**함으로써 렌더링 성능을 획기적으로 개선하겠습니다.

## 오픈 질문

> [!NOTE]
> 1. 지도 시각화 탭 상단에 시간대(0시 ~ 23시)를 제어할 수 있는 **슬라이더(`st.slider`)**를 제공할 예정입니다. 시간대를 조절하면 즉각적으로 지도의 생활인구 밀도 색상이 변경되도록 동기화하겠습니다.
> 2. 지도 시각화 시, 구 단위(자치구별)와 동 단위(행정동별)를 사용자가 자유롭게 전환하여 볼 수 있도록 하는 **라디오 버튼 토글 필터**를 제공할 계획입니다. 동의하시나요?

## 제안된 변경 사항

### 1. 환경 및 패키지 설정
- `folium` 및 `streamlit-folium` 패키지가 가상환경(`.venv`)에 이미 설치된 상태이므로 추가 설치 없이 사용합니다.

### 2. 소스 코드 구현
#### [MODIFY] [app.py](../src/app.py)

- **GeoJSON 로딩 및 캐싱 로직 추가:**
  - `@st.cache_data`를 활용하여 `seoul_sig.geojson` 및 `seoul_dong.geojson`을 로드하는 함수를 구현합니다.
- **새로운 탭 추가:**
  - 기존 3개의 탭에 더해 네 번째 탭인 `"🗺️ 공간(지도) 시각화"` 탭을 추가합니다.
- **지도 시각화 탭 레이아웃 및 로직 구현:**
  - **선택 필터:** 
    - 공간 단위 선택: `[자치구별, 행정동별]` 라디오 버튼
    - 시간대 선택: `[0시 ~ 23시]` 슬라이더 위젯
  - **데이터 집계:**
    - 선택된 시간대와 자치구 필터에 맞춰 데이터를 필터링하고 평균 생활인구수를 집계합니다.
    - 동별 조인을 위해 `df['adm_cd2_str'] = df['행정동코드'].astype(str) + '00'` 컬럼을 동적으로 매핑합니다.
  - **GeoJSON 필터링:**
    - 특정 자치구 필터가 적용된 경우, `seoul_dong.geojson`에서 해당 자치구(`sggnm` 프로퍼티)에 매칭되는 features만 필터링하여 GeoJSON 객체를 동적으로 생성합니다.
  - **Folium Choropleth 구성:**
    - 중심 좌표를 서울시 중심(약 `[37.5665, 126.9780]`)으로 설정하되, 특정 자치구를 선택하면 해당 자치구의 중심점(GeoJSON 폴리곤 중심)으로 지도의 중심과 줌 레벨을 동적으로 변경하여 뷰포트를 최적화합니다.
    - 생활인구 밀도에 따라 적절한 컬러 맵(예: `YlOrRd`)으로 색상을 다르게 표현합니다.
    - 마우스 오버 시 구 명칭 또는 행정동 명칭과 생활인구수가 툴팁으로 표시되도록 `folium.features.GeoJsonTooltip`을 적용합니다.
    - `streamlit_folium.st_folium`을 통해 대시보드 화면에 지도를 렌더링합니다.

## 검증 계획

### 수동 검증 (Streamlit 실행 및 확인)
1. Streamlit 서버 구동 상태에서 웹 브라우저를 통해 대시보드에 접속합니다.
2. 네 번째 탭 `"🗺️ 공간(지도) 시각화"`가 정상적으로 노출되는지 확인합니다.
3. 공간 단위를 `자치구별`로 설정하고 시간대 슬라이더를 0시에서 14시 등으로 옮겼을 때 지도가 실시간으로 다시 그려지며 인구 분포 색상이 어두워지거나 밝아지는지 검증합니다.
4. 공간 단위를 `행정동별`로 설정하고 특정 자치구(예: 종로구)를 사이드바에서 선택했을 때, 종로구 중심부만 집중적으로 지도에 렌더링되는지 확인합니다.
5. 마우스 포인터를 구/동 폴리곤 위에 올렸을 때 툴팁 정보(지역명 및 생활인구수)가 올바르게 팝업되는지 검증합니다.
6. 대시보드 수정 및 검증 과정을 완료한 후, 수정 결과를 [walkthrough.md](../docs/walkthrough.md)에 업데이트하여 반영합니다.
