# 🛍️ 온라인 리테일 콘텐츠 기반 추천 시스템 성능 분석 및 모델 비교 보고서

## 1. 개요 (Overview)
본 보고서는 `online_retail (1).parquet` 데이터셋을 활용하여 상품명과 상품코드를 정제한 후, **TF-IDF 벡터화** 방식과 사전학습된 언어 모델 **Sentence-Transformer (`all-MiniLM-L6-v2`) 문장 임베딩** 방식의 콘텐츠 기반 추천 시스템(Content-based Recommendation System)을 구축 및 비교 분석한 결과를 담고 있습니다.

---

## 2. 데이터 정제 및 전처리 (Data Preprocessing)
- **원본 데이터셋**: 총 541,909건의 거래 내역
- **정제 작업**:
  - `Description` 결측치 및 양끝 공백 처리, 대문자 정규화 및 수수료/시스템 항목(`POST`, `D`, `M`, `BANK CHARGES` 등) 제거
  - `InvoiceNo` C(취소건), 수량/단가 0 이하 이상치 제거
  - `StockCode`와 `Description` 기준 최다 빈도 상품명을 유일(Unique) 매핑하여 **3,917개의 고유 상품 데이터셋**(`cleaned_products.parquet`) 구축

## 3. 추천 성능 평가 지표 (Evaluation Metrics)

300개의 무작위 쿼리 상품에 대해 상위 $K=10$개의 추천 상품을 산출하고, 4가지 정량 지표를 측정하였습니다.

| 평가 지표 (Metric) | TF-IDF 추천 모델 | Pretrained Embedding 모델 | 지표의 해석 및 시사점 |
| :--- | :---: | :---: | :--- |
| **Average Similarity (평균 코사인 유사도)** | **0.3201** | **0.6535** | 쿼리 상품과 추천 상품 간 텍스트/의미론적 코사인 유사도 평균. 문장 임베딩 방식이 텍스트 의미 연관성을 훨씬 강력하게 포착함을 입증 (약 +104% 우수). |
| **Intra-List Diversity (ILD / 다양성)** | **0.7494** | **0.4184** | 추천 리스트 내 상품들 간 상호 거리($1 - \\text{similarity}$). TF-IDF는 희소 벡터 특성상 키워드 매칭 외 항목들과의 거리가 멀어 다양성이 높게 나타남. |
| **Catalog Coverage (%) (카탈로그 커버리지)** | **48.74%** (1,909개) | **49.63%** (1,944개) | 전체 3,917개 상품 중 추천 목록에 최소 1회 이상 등장한 비율. 두 모델 모두 약 50%의 높은 커버리지를 기록하며 롱테일(Long-tail) 아이템을 고르게 제안함. |
| **Novelty (희소성/신선도 점수)** | **13.2633** | **13.2808** | 추천된 아이템의 희소성 정보량 ($-\\log_2 P(\\text{item})$). 두 모델 모두 일반 인기 상품에 치우치지 않고 비주류 희소 상품을 균형 있게 탐색함. |

## 4. 두 추천 모델의 특징 및 장단점 비교

### 1) TF-IDF 기반 추천
- **장점**: 연산 및 메모리 효율성이 뛰어남. 쿼리 상품의 특정 핵심 단어(예: `HEART`, `BOTTLE`, `RED`)가 완벽히 포함된 직관적인 상품 위주로 추천되므로 정밀도(Precision) 느낌을 줌.
- **단점**: 동의어(Synonym)나 의미상 유사한 단어(예: `BAG` ↔ `POUCH`, `BOX` ↔ `CONTAINER`)를 서로 다른 단어로 인식하여 텍스트표현의 한계가 존재함.

### 2) Pretrained Sentence Embedding (`all-MiniLM-L6-v2`) 기반 추천
- **장점**: 문장의 딥러닝 인코딩 표현을 통해 단어의 의미적 맥락(Semantic Context)을 파악함. 표면적 철자가 달라도 카테고리/용도/디자인 컨셉이 통하는 상품을 추천(High Serendipity).
- **단점**: 밀집 벡터(Dense Vector) 저장 공간이 필요하며 인코딩 시 추가적인 뉴럴 넷 연산 시간이 요구됨 (캐싱으로 보완 완료).
